# 复习分册的格式与写作规则

脚本（lint / checklist / md_to_notion）都按这个格式解析，格式走样会导致答案折叠失败或知识点漏进数据库，所以每册都照这个写。

## 目录与文件命名

```
<资料目录>/
├── 00_总览与知识点总清单.md     # 总入口：考试结构、权重、计划、教材差异表、总清单
├── 01_<学科>_<教材>_第1-5章.md   # 按教材章节切册，一册 3–7 章、约 4–8 万字为宜
├── ...
└── 09_公式与常数速查.md          # 无 "## 章" 的单页分册（转换时用 --single 09）
```

- 文件名 `NN_` 两位编号开头；`00_` 是总览，不参与转换（它变成 Notion 总入口页）。
- 一册对应指定教材的连续章节；非指定教材内容（工艺、电路、数学等）按"模块"组织，模块标题里注明参考书。

## 单册模板

```markdown
# 半导体物理（刘恩科 第8版）复习资料 · 第1–5章

> 本册覆盖……（一两句话：范围、在考试中的地位、哪几章是计算题重点）

**通用约定**
- 符号、常数取值；不同教材取值不同的地方在这里写明（如 nᵢ 取 1.0×10¹⁰ 还是 1.5×10¹⁰）。

---

## 第1章 半导体中的电子状态（教材 p1）

### 知识点清单
- [ ] ★★★ 有效质量（p11）
- [ ] ★★ 导体、半导体、绝缘体的能带（p10）
- [ ] ★ 回旋共振（p16）

### 核心内容

#### 1.3 半导体中电子的运动——有效质量（p11）
- 要点、公式、图像描述、变化趋势……

### 易错点
1. ……

### 典型题（附答案与解析）

**1.（单选）** 下列材料中属于直接带隙半导体的是：
A. Si　B. Ge　C. GaP　D. GaAs
答案：D。解析：……

**2.（计算）** ……
答案：……
解析：……（可多行，直到下一题）

### 教材课后习题（必做）
- 第1章习题 1、3、5（p34）
```

## 硬性格式（脚本靠它解析）

| 元素 | 写法 | 为什么 |
|---|---|---|
| 章 | `## 第N章 标题（教材 pXX）` | 每个 `##` 变成一个 Notion 子页面；括号说明会移到页首引用 |
| 四个小节 | `### 知识点清单` / `### 核心内容` / `### 易错点` / `### 典型题…` | lint 检查；数据库只从「知识点清单」取行 |
| 知识点 | `- [ ] ★★★ 名称（p页码）` | 星级 1–3 个；末尾括号页码进数据库「教材页码」字段 |
| 题目开头 | `**1.（单选）**` 或 `**题1（计算）**` | 只在「典型题」小节内识别 |
| 答案 | 以 `答案` 或 `**答案` 开头的一行，解析可跟多行 | 从这一行起到下一题全部放进折叠块 |
| 导言、附注、符号对照 | `## 导言…` / `## 附：…` / `## …符号对照…` | 不建子页面，并入分册页。教材里有实质内容的"附录X"要当普通章写（如 `## 第14章（附录B）…`），否则会被并掉 |

核心内容里的小标题可以用 `#### 1.3 …（p11）` 或加粗 `**1. …**`，不影响解析。

## 内容规则

1. **指定教材优先**：概念、符号、结论以考试指定教材为准；其他书只帮助理解。两书说法不同时，在正文写明"刘恩科记作…，施敏记作…"，并汇总进 00 总览的差异表。
2. **页码一律用印刷页码**：扫描 PDF 的 PDF 页码和书上页码有固定偏移，先校准（见 SKILL.md 第 1 步），不要把 PDF 页码写进资料。
3. **数值要标来源和分歧**：常数（nᵢ、N_v、ε_r…）不同教材取值不同，写出取值并注明"考试按题目给定值"。
4. **算例必须复算**：计算题的数值写完后用 Python 复算一遍，ln、指数、量级错误最常见。
5. **星级**：★★★ = 必考/计算题高频；★★ = 常考概念；★ = 了解。★★★ 一般占 35–45%。
6. **题型覆盖**：每章 4–12 题，单选、判断、填空、计算、简答混合；★★★ 知识点至少各有一题。
7. **课后习题**：指定教材每章列出必做的课后习题号和页码。
8. **诚实标注来源**：如果教材是扫描件且没做 OCR，资料的章节结构和页码来自目录，正文是按学科通识写的——在 00 总览里明说这一点，用户会问"这是按我的教材写的吗"。
